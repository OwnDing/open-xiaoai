# 《家的大脑》· 分镜脚本

> 片名：**《家的大脑》**
> 副标题：如何 DIY 一个全网最智能的 AI 家庭管家
> 规格：1920×1080 · 24fps · 2.39:1 电影遮幅 · H.264 · 约 2 分 50 秒
> 最终时间码以 `build/timeline.json` 为准（由配音实际时长自动排布，本文档中的时间为约数）。

## 一、创意

**一句话**：用一束看得见的“声音之光”，把看不见的 AI 管家变成一段旅程：你的声音从一台普通音箱出发，
在家里的 mini PC 上被听懂、被思考，再去点亮不同品牌的设备。这束光，始终没有离开家。

**核心主张**：家的大脑，就该住在家里。

这句话同时回答了三个问题：

| 现在的智能家居 | 我们的做法 | 片中的视觉 |
|---|---|---|
| 大脑不够聪明：只认命令，听不懂意思 | 大模型 + Hermes 智能体：理解意图、有记忆、能被教会 | 同一句“我有点冷”，前后两种结果 |
| 品牌各自为政：一个品牌一个 App | Home Assistant 统一接入米家、海尔等品牌 | 设备困在各自的 App 气泡里 → 光丝把它们连在一起 |
| 隐私交给云端：AI 越懂你，家里越没有秘密 | 唤醒、语音识别在家里的 mini PC 上完成，只把文字发给大模型 API | 透明的房子，声音飞向云端 → 光丝回流，家被一层光罩住 |

**叙事手法**

1. **先给魔法，再讲道理**：开场就是一句“我回来了”，整个家依次亮起。观众先被画面抓住，再看为什么、怎么做。
2. **首尾呼应**：开场的“我回来了”在第 5 幕揭晓：这条规矩是三天前用一句话教会的。
3. **同一句话，两种结果**：痛点里说“我有点冷”被回绝；体验段说同一句话，空调调高、还约好睡前提醒。

**必须讲清楚的事实**（均来自本项目的真实能力，扩展部分明确标注）

1. DIY 只需要两样硬件：一台带麦克风的音箱（蓝牙音箱、USB 麦克风或刷机后的小爱音箱）+ 一台常开的 mini PC。
2. 说“你好小七”唤醒；唤醒和语音识别（SenseVoice，约 0.2 秒出文字）都在本地运行，录音不上传。
3. 发给大模型 API 的只有识别好的文字；Hermes 智能体负责思考、记忆、技能；Home Assistant 连接米家、海尔等品牌。
4. 用一句话就能教会场景（“以后我说‘我回来了’……”）；跨品牌联动（海尔洗衣机洗完，由音箱播报）。
5. 摄像头识别危险、陪孩子写作业是**扩展方向**，画面上标注“扩展”。

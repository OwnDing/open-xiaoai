- Windows `AudioEndpoint` 枚举到蓝牙输入端点，状态 `OK`。
- 输入端点 GUID：`{C09CC07A-0647-4100-9ACE-FA1FB2E908A2}`，对应 `MMDEVAPI` capture 端点。

- 这些格式可能来自 Windows 音频转换，不代表蓝牙链路的实际编解码采样率。
- P0.5 复查（同日）：WASAPI 报告该输入为 8000 Hz，本次真人录音在 4 kHz 以上几乎没有能量，确认链路是 8 kHz 窄带（CVSD），48 kHz 是 Windows 转换后的格式。见 [P0.5 硬件测试记录](voice-terminal-p05-hardware-tests.md)。

## 实际采集

### 采集方法

先进行了不要求用户朗读的基线采集，再在用户回复“准备好了，可以开始”后采集真人语音。明确指定蓝牙输入名称，不使用默认输入、loopback 或 RDP 重定向输入。

FFmpeg 输入实际打开为 48 kHz、单声道、16 bit PCM，输出重采样到 16 kHz、单声道、16 bit WAV。真人测试约定句为“你好小七，这是蓝牙麦克风输入测试，一二三四五”，提示朗读两遍，中间停顿。

真人采集命令的核心参数如下（`$wav` 为临时输出文件路径）：

```powershell
& 'C:\Program Files\ffmpeg\bin\ffmpeg.exe' `
  -hide_banner -nostdin -nostats -y `
  -f dshow -audio_buffer_size 100 -sample_rate 48000 -channels 1 `
  -i 'audio=耳机 (京鱼座蓝牙小黑胶)' `
  -t 20 -af 'asetpts=N/SR/TB' -ac 1 -ar 16000 -c:a pcm_s16le $wav
```

实际执行通过 PowerShell `Start-Process` 启动并设置超时，只在测试进程超时时终止该进程。两次采集均正常结束，没有触发超时。

真人采集进程时间：2026-10-04 20:48:52 至 20:49:14（UTC+08:00），含设备初始化；WAV 有效采样时长为 20.000 秒。

基线最初指定 `-t 6`，但 DirectShow 起始时间戳导致实际 WAV 只有 5.292 秒。真人测试加入 `asetpts=N/SR/TB` 后得到准确的 20 秒采样。文档以 WAV 实际采样数为准，不以命令中的目标时长代替测量结果。

这些电平证明收到非零信号且没有数字满幅削波，不能独立证明人声内容、信噪比或主观音质。基线并非校准静音环境，不能直接将两次 RMS 相减作为精确人声信噪比。

### 本地识别核验

将 WAV 临时复制到现有小智容器的 `/tmp`，直接使用已安装的 Sherpa-ONNX SenseVoice 模型识别。使用 2 个 CPU 线程，未联网下载模型，未调用 Hermes、LLM 或智能家居动作链路。

同一段真人录音的识别结果如下：

| 输入范围 | 原始识别结果 |
| --- | --- |
| 完整 20 秒 | `麦克风输入测试1。` |
| 0–10 秒 | `麦克风输入试1345你小七345。` |
| 10–20 秒 | `你好这是蓝牙麦克风输入测试。` |

分段结果包含约定测试句的核心内容，确认该蓝牙麦克风确实采集到了可识别的人声。长录音与分段识别结果存在差异；这不是额外一次硬件录音，不能当作多次稳定性测试。后续正式对话应使用 VAD 判句，避免把多轮语音整段交给 ASR。

目前尚不能仅凭这次测试判断漏字源于收音距离、环境噪声、蓝牙通话模式还是 ASR 分段，需要后续短句、距离和安静环境对照测试。

## 结论与待验收项目

**通过：这台 mini PC 上的京鱼座蓝牙小黑胶支持实际麦克风输入，可以继续作为新增语音终端的硬件。**

- 播放：用户确认可用；本轮没有重复播放测试。
- 输入：指定设备成功打开、持续输出 20 秒采样，包含本地 ASR 可识别的人声。
- 用户回听确认（2026-10-04）：录音是本人刚才说的话；确认本次未做软件降噪。输入来源已获得真人核验，降噪和实际对话质量仍属于后续优化与验收。
- 本轮没有修改默认音频设备、驱动、蓝牙 profile、麦克风权限、音箱固件或服务配置。
- 测试后现有小爱桥接、小智后端、Hermes、Home Assistant 和 Sherpa TTS 容器仍在运行。
- 待验收：远场和噪声环境识别质量、输入开启时的播放质量、播放后的收音恢复、回声、蓝牙断线重连、RDP 断开、锁屏/注销/休眠恢复，以及 Linux/macOS 的实际硬件表现。
- 尚未实现跨平台终端、按设备 TTS 或双端并发；本次硬件通过不表示整套扩展已经完成。

# Open-XiaoAI 宣传片 · 分镜脚本

> 片名：**《小爱，换个大脑》**
> 副标题：让小爱音箱，成为你的贴身家庭管家
> 规格：1920×1080 · 30fps · H.264 · 约 2 分 10 秒
> 最终时间码以 `build/timeline.json` 为准（由配音实际时长自动排布，本文档中的时间为约数）。

## 一、创意概述

**一句话**：同一台小爱音箱，保留原来的小爱，再唤醒一位会思考、有记忆、能管全屋设备的 AI 管家。

**叙事手法：「同一句话，两种回答」**
前半段让用户对原生小爱说两句很日常的话——“我有点冷，还有点困”、“还记得我睡觉空调开几度吗”，小爱答不上来；
后半段用户对新 AI「小七」说出同样的话，得到完全不同的结果。观众不需要看懂技术，就能直观感受到差别。

**三个痛点 → 三个回应**

| 痛点 | 画面表现 | 接入 AI 后的回应 |
|---|---|---|
| 01 只会听指令，听不懂意思 | “我有点冷，还有点困” → “抱歉，我没有听懂” | 小七调高空调，并主动约好睡前提醒 |
| 02 聊过就忘，没有记忆 | “还记得我睡觉空调开几度吗” → “我还在学习中” | 三天前说过一次，今晚“我睡觉了”自动按 25° 设置 |
| 03 设备分属不同 App，非米家设备管不了 | 设备图标被困在各自的 App 气泡里，连线断开 | Home Assistant 统一接入，一句话同时关米家灯、拉其他品牌窗帘 |

**关键信息（必须讲清楚）**
1. 原来的小爱功能一个不少，喊“小爱同学”照常用；喊“你好小七”唤醒 AI 管家。
2. 链路：小爱音箱 → 语音识别 → Hermes 智能体（大模型 · 记忆 · 技能 · 联网）→ Home Assistant → 米家 & 其他品牌设备。
3. Home Assistant 用小米账号授权登录，米家设备自动同步。
4. AI 有长期记忆，是懂你的家庭管家。

## 二、视听风格

| 项目 | 设定 |
|---|---|
| 场景 | 一套三居室的 3D 微缩“剖面屋”（书房 · 客厅 · 卧室），外加一个黑色产品摄影棚 |
| 画幅 | 痛点段落使用 2.39:1 电影遮幅；转折时遮幅向上下打开，画面“被打开” |
| 色调 | 痛点：冷青灰、低饱和、偏暗；转折后：暖琥珀 + 紫色点缀，饱和度回升 |
| 灯光语言 | 音箱顶部光环是贯穿全片的主角：原生小爱 = 冷白色；AI 小七 = 琥珀→紫色渐变，并随说话声音起伏 |
| 镜头 | 慢推、环绕、升降、焦点转移（rack focus），浅景深，全程无硬切，以叠化、光线扫过、遮幅开合做转场 |
| 字体 | PingFang SC（标题 Semibold / 字幕 Regular），英文 Avenir Next |
| UI | 磨砂玻璃对话气泡（用户在右、音箱在左）、设备状态胶囊（✓ 动效）、极简连线架构图 |
| 配音 | 旁白：沉稳男声；用户：年轻男声；音箱：温暖女声（小七沿用小爱原生音色的定位） |
| 音乐 | 原创合成配乐：前段低沉氛围 + 紧张脉冲 → 转折处上扬冲击 → 大调温暖琶音 → 结尾长音收束 |
| 音效 | 唤醒提示音、UI 点击、灯光开关、窗帘电机、故障（glitch）、呼啸转场、低频冲击 |
